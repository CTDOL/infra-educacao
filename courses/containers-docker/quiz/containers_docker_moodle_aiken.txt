Qual recurso do kernel Linux limita o uso de CPU e memória de um container?
A. namespaces
B. cgroups
C. iptables
D. systemd
ANSWER: B

Qual é a principal diferença entre um container e uma máquina virtual?
A. O container compartilha o kernel do host, sem sistema operacional completo próprio
B. O container exige um hypervisor
C. O container sempre usa mais memória
D. O container não pode rodar Linux
ANSWER: A

O que é uma imagem Docker?
A. Um container em execução
B. Um modelo somente leitura, formado por camadas, a partir do qual containers são criados
C. Um volume de dados
D. Um arquivo de rede
ANSWER: B

Qual comando lista os containers em execução?
A. docker images
B. docker logs
C. docker ps
D. docker pull
ANSWER: C

O que acontece com os dados gravados na camada do container quando ele é removido?
A. Ficam guardados no host
B. São enviados ao registry
C. São perdidos
D. Migram automaticamente para um volume
ANSWER: C

Qual instrução do Dockerfile executa um comando durante a construção da imagem?
A. CMD
B. RUN
C. EXPOSE
D. FROM
ANSWER: B

Por que copiar o arquivo de dependências antes do restante do código em um Dockerfile?
A. Para aproveitar o cache de camadas e evitar reinstalar dependências a cada mudança no código
B. Porque o Docker exige essa ordem
C. Para reduzir o tamanho do código-fonte
D. Para dispensar o comando RUN
ANSWER: A

Qual é a forma recomendada de tratar senhas e chaves em uma imagem Docker?
A. Gravá-las no Dockerfile
B. Copiá-las com COPY para dentro da imagem
C. Não incluí-las na imagem e fornecê-las em tempo de execução por um mecanismo seguro
D. Publicá-las no registry
ANSWER: C

Como fazer dois containers se comunicarem pelo nome?
A. Colocá-los na mesma rede definida pelo usuário
B. Usar sempre o IP do host
C. Publicar todas as portas com -p
D. Executá-los como root
ANSWER: A

O que faz a opção -p 127.0.0.1:8080:80 em docker run?
A. Publica a porta 80 do container apenas na interface local do host, porta 8080
B. Publica a porta 8080 do container em todas as interfaces
C. Bloqueia a porta 80
D. Cria um volume
ANSWER: A
